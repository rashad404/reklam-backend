# Reklam.biz full design rebuild

Requested outcome: replace the starter design with a coherent modern production product, then deploy it. This is the current visual plan; older visual prescriptions are superseded. Financial functionality remains excluded.

## Implementation scope

1. Rebuild the public page composition, typography, spacing, navigation and footer across home, advertiser, publisher, formats, help and legal pages.
2. Replace generic sample advertising with localized Reklam.biz house ads and a functional format selector. Use the existing shared renderer and real campaign-creation destinations.
3. Rebuild the account shell with desktop sidebar, mobile navigation, account menu and clearer dashboard actions. Restyle campaign editing, publisher setup, reports, moderation, support and settings consistently.
4. Remove public demo/rollout/payment disclaimers. Keep payment availability copy only on payment pages. Use an account icon for sign-in.
5. Verify real local fixture journeys, AZ/EN/RU layouts, desktop/mobile and both themes. Fix accessibility or functional regressions.
6. Build a fresh production frontend release, switch only Reklam's PM2 process, and verify the live product, SEO and performance. Retain the previous release for rollback.

## Chosen direction

Confident typography, a warm public canvas, ink panels and a red identity. A working ad studio provides the first viewport's product detail. Account screens use a quiet neutral canvas and clear persistent navigation. No invented metrics or customers.

## Acceptance and evidence

Implementation and local checks are complete; deployment evidence is recorded in audits/2026-09-12-design-rebuild.md. The canonical visual rules are in design.md. Backend behavior, data and payment processing are outside this visual change.
